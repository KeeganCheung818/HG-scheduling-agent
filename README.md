# HG-scheduling-agent

Git_Repository_for_Ontology

## 在线开发

[打开或创建 GitHub Codespace](https://github.com/codespaces/new/KeeganCheung818/HG-scheduling-agent?resume=1)

仓库提供通用开发容器配置，统一团队的基础开发环境，并预装 Visual Studio Live Share 扩展。当前仅初始化协作环境，尚未导入业务代码。

## 团队协作

- 每位成员使用自己的 GitHub 账号创建 Codespace；运行时间和存储按各自账号的配额及计费设置计算。
- 需要共同编辑同一个环境时，由环境所有者在 VS Code 中通过 Live Share 发起协作并分享邀请链接。
- 仓库公开可读；直接推送需要仓库协作者权限。尚未获得权限的成员可通过 Fork 和 Pull Request 提交修改。
- 在功能分支开发，通过 Pull Request 合并到 main。
